# ADR Format

The active replacement is `skills/plan/documentation.md`, which stores ADRs inside each work packet.

Legacy ADRs lived in `docs/adr/` and used sequential numbering:

```text
0001-short-title.md
0002-next-decision.md
```

Create an ADR only when the decision is hard to reverse, surprising without context, and the result of a real trade-off.
