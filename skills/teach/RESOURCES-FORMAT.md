# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Knowledge for
lessons is drawn from here. Wisdom comes from the communities listed here.

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ by Author](url)
  What it covers. Use for: when to reach for it.

## Wisdom (Communities)

- [Community](url)
  Why it is high-signal. Use for: the kind of question to take there.
```

## Rules

- High-trust only: **primary sources**, recognised experts, peer-reviewed work,
  and communities with strong moderation.
- Annotate every entry with one line: what it covers and when to reach for it.
- Group by Knowledge / Wisdom. A resource may appear in only one group.
- If no good resource exists for an area the mission needs, add a `## Gaps`
  section. That drives future search.
- Remove a resource that turned out wrong, shallow, or off-mission.
- If the user has opted out of communities, record that here.
