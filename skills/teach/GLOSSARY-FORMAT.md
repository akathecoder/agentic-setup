# GLOSSARY.md Format

`GLOSSARY.md` is the canonical language for this teaching workspace. Lessons,
reference docs, and learning records use its terms.

```md
# {Topic} Glossary

{One or two sentences describing the topic.}

## Terms

**Term**:
One- or two-sentence definition of what it is.
_Avoid_: near-synonyms that invite drift
```

## Rules

- Add a term only when the user can use it correctly. The glossary records
  compressed knowledge; it is not how they first learn a concept.
- When several words exist for the same concept, pick one and list the rest under
  `_Avoid`.
- Keep definitions tight. Define what the term is.
- Once a term is in the glossary, use it inside other definitions.
- Group under subheadings when clusters emerge.
- If a term is used loosely in the field, state the resolution used here.
- Update in place as understanding deepens.
