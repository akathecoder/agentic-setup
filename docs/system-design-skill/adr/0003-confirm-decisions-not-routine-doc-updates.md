# Confirm Decisions, Not Routine Document Updates

The `design` skill should explicitly confirm architectural, product, or design decisions with the user before recording them as chosen. It may update design documents with agreed facts, open questions, todos, and conversation context without asking for separate approval on every document edit.

## Consequences

The skill remains a pair-design workflow without becoming blocked by mechanical documentation updates. Decision records must still show the proposed decision and reasoning before the user confirms the choice.
