# Name the Skill `publish-confluence`

The active skill should be named `publish-confluence`. The user explicitly chose this name because the skill's job is to publish local documentation to Confluence.

## Considered Options

- `write-confluence` - initially chosen because it matched `write-jira`, but replaced by the user's preferred name.
- `publish-confluence` - chosen because it directly names the publication action and Confluence target.
- `publish-docs` - shorter, but less clear about Confluence as the destination.

## Consequences

The implemented skill folder should be `skills/publish-confluence/`, and README should list `publish-confluence` as an active internal skill.
